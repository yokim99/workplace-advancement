# 新方案的汇报心法

## 一句话总结

**新方案不只是把事想清楚，更要让领导看到你的视野、根基和主动性。**

---

## 核心认知

在看新方案设计时，领导给出了五条指导，每条都直指职场进阶的关键：

> "视野要放大，业务底座要打好（学会借助周边团队的力量），事要自己想着做（客户需求，业界对比友商），找领导多聊，要资源人脉，要培养个人竞争力影响力。"

---

## 策略拆解

### 1. 视野要放大

方案不能只盯着自己的一亩三分地。

| 维度 | 怎么做 |
|------|--------|
| 向上看 | 这个方案跟公司/部门战略怎么对齐？ |
| 向外看 | 竞品 / 同行 / 行业标杆是怎么做的？ |
| 向前看 | 做完这一步，下一步可以怎么做？ |

### 2. 业务底座要打好

不是什么事都自己扛。好的方案应该展示你如何**调动资源**：

- 识别哪些环节可以借助周边团队的力量
- 讲清楚你准备怎么协同、对齐、推进
- 让领导看到你有"借力"的能力，不是单打独斗

### 3. 事要自己想着做

不等着被安排，而是主动：

- 从**客户需求**出发 — 他们真正的痛点是什么
- 做**业界对标** — 别人已经做到的，我们可以学什么；别人没做到的，我们可以突破什么
- 带着自己的判断去见领导，而不是带着一张白纸

### 4. 找领导多聊

汇报不是一次性的事。方案孵化阶段就多聊：

- 聊方向 — 确认大方向对不对
- 要资源 — 人、钱、权限、信息
- 要人脉 — 让领导帮你打通跨团队协作的链路

### 5. 培养个人竞争力和影响力

每一次方案都是一次练兵：

- 方案本身 → 专业能力
- 跨团队协同 → 组织影响力
- 汇报逻辑 → 表达能力和战略思维
- 成果落地 → 可信度和口碑积累

## 行动清单

- [ ] 写方案前，先做竞品/行业调研，找到对标
- [ ] 标注方案中哪些需要跨团队配合，提前盘点利益相关方
- [ ] 方案孵化阶段至少找领导聊 2 次，每次带着具体问题
- [ ] 完成后复盘：这次方案帮我提升了哪项能力
