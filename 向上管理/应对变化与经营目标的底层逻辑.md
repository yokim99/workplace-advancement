# 应对变化与经营目标的底层逻辑

## 一句话总结

**变化是常态，但万变不离其宗——始终围绕经营目标做判断，方向就不会偏。**

---

## 核心认知

大领导说过一句话："变化是正常的，但是万变不离其宗。"

这里的"宗"是什么？

| 维度 | 说明 |
|------|------|
| **用户数** | 规模增长 → 市场占有率 → 生态壁垒 |
| **收入** | 商业价值 → 可持续性 → 资源投入的底气 |
| **用户满意度** | 留存基础 → 口碑传播 → 长期竞争力 |
| **战略重点项目** | 方向锚点 → 不可替代性 → 组织价值 |

---

## 策略拆解

### 1. 面对变化时，先问四个问题

每次方向调整、架构重组、需求变更时，用这四个问题校准：

1. 这个变化对**用户数**有帮助吗？
2. 这个变化对**收入**有帮助吗？
3. 这个变化会提升还是降低**用户满意度**？
4. 这个变化是否服务于**战略重点项目**？

至少命中两个，才算靠谱的变化。

### 2. 区分"战术变化"和"战略漂移"

- **战术变化**：手段调整，不影响核心目标（如换了推广渠道、改了运营节奏）→ 正常
- **战略漂移**：核心目标摇摆不定（如这月冲用户数、下月砍成本、再下月追收入）→ 危险信号

### 3. 用"宗"来决策日常工作优先级

当同时有多个任务压过来时，以四个维度为排序标准，离经营目标越近的事越优先做。

---

## 行动清单

- [ ] 了解所在团队的经营目标是什么（用户数/收入/满意度/重点项目）
- [ ] 每次接新任务时，先对号入座：它属于四个维度的哪一个
- [ ] 做周报/月度总结时，将成果映射到经营目标上
- [ ] 发现任务与经营目标无关时，有意识地沟通调整优先级
