# 应对平级同事指导的策略

> **主题**：平级协作 · 边界管理 · 姿态维护
> **日期**：2026-07-24

## 核心观点

工作中有其他人（尤其是平级同事）要"指导"你的工作时，一定要谨慎。不要把自己的位置放低，要强势一些。根据不同情况，用不同方式回应，既不失礼貌，也不失立场。

## 策略拆解

### 1. 原则：不卑不亢，守住自己的位置

- 平级同事之间，不存在"指导"与"被指导"的上下级关系
- 对方试图"指导"你时，本质是在试探你的边界、建立心理优势
- **核心原则**：可以听取建议，但绝不接受居高临下的姿态

### 2. 场景一：他"指导"的事你已经在做

这是最常见的场景，也是最需要强势回应的时刻。

**正确做法**：大大方方讲出来你的成果和进展

- "这个事我这边已经在推进了，目前进展是……"
- "对，这块我也在关注，上周已经完成了……"

**为什么要这样做**：
- 表明你对自己工作有掌控力，不需要别人来"教"
- 用事实说话——成果比解释更有力
- 暗示对方：你的"指导"是多余的，我走在你前面

### 3. 场景二：他"指导"的事你确实没做

即使没做，也不要表现出心虚或被动。

**正确做法**：讲出自己的思考

- "这块我目前还没启动，我的考虑是……（说明优先级判断/资源限制/策略选择）"
- "这个方向我有想过，我的思路是……"

**为什么要这样做**：
- 表明你没做不是因为没想到，而是有主动的判断和取舍
- 把对话从"你该做什么"拉到"你怎么想的"，形成平等交流
- 展示你的思考深度，让对方知道你不好"拿捏"

### 4. 心态建设

| 常见心态 | 应调整为 |
|---------|---------|
| "他说得也有道理，我虚心听听" | 道理可以听，但姿态不能低 |
| "别伤了和气，先应着" | 一味退让只会让对方得寸进尺 |
| "我确实没做，心虚" | 没做有没做的理由，讲出来就是你的主动权 |
| "直接怼回去" | 不需要对抗，用成果和思考"降维"回应即可 |

## 行动清单

- [ ] 识别"指导"场景：对方是在平等交流，还是在居高临下？
- [ ] 快速判断：这件事我是否已经在做？
- [ ] 已在做 → 准备好成果数据，大方展示
- [ ] 没在做 → 准备好自己的思考逻辑，主动表达
- [ ] 全程保持平稳语气，不急不躁，用内容而非情绪取胜

## 一句话总结

**平级之间没有"指导"，只有交流。用成果回应质疑，用思考回应空白，姿态不低，底气才足。**
