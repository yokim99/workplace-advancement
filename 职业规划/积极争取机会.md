# 积极争取：机会不会主动找你

## 一句话总结

**职场中，起码要表现得积极。主动争取机会，不然好事凭什么轮到你。**

---

## 核心认知

这是最朴素也最容易忘记的道理。

职场的资源分配不是"按需分配"：
- 好项目、好机会、好资源永远是稀缺的
- 领导不会花精力去猜"谁可能感兴趣"
- 主动的人先拿到信息、先进入视野、先被想到

---

## 策略拆解

### 1. "表现得积极"本身就是信号

哪怕你内心佛系，行为上也不能佛系。领导判断一个人有没有潜力，很大程度看**主动性和饥饿感**：

| 不积极的表现 | 积极的表现 |
|-------------|-----------|
| 等分配任务 | 主动问"有什么我能参与的" |
| 完成任务交差 | 做完后复盘并主动分享 |
| 只在工位上默默干活 | 主动在合适的场合展示成果 |
| 领导不提的事不做 | 发现自己能做的事主动提方案 |

### 2. 三个关键时机主动出击

| 时机 | 怎么做 |
|------|--------|
| 有新项目启动时 | 主动表达兴趣，哪怕只是"先了解" |
| 领导聊到团队需求时 | 主动说我在这方面有经验/想尝试 |
| 日常 1-on-1 时 | 主动聊成长方向，"我想在 XX 方向上多承担" |

### 3. 主动 ≠ 喧宾夺主

- 主动是**展现意愿和执行能力**，不是抢话、抢功
- 最好的主动是：**提前准备好，机会来的时候刚好能接住**
- 日常铺垫比临场表现更重要

## 行动清单

- [ ] 这周主动找领导聊一个你想参与的方向
- [ ] 关注组内/跨部门的新项目动态，找到想参与的一个
- [ ] 保持"饥饿感"的日常表现——在合适场合展示你的思考和进展
- [ ] 记住：主动的人不是运气好，是在"大概率"上不断下注
