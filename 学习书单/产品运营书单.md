### 1. 上瘾：让用户养成使用习惯的四大产品逻辑

| 项目 | 内容 |
|------|------|
| **作者** | 尼尔·埃亚尔（Nir Eyal） |
| **出版年** | 2014 |
| **分类** | 用户行为 · 习惯养成 · 产品设计 |
| **适合人群** | 产品经理、用户运营、增长运营 |
| **阅读状态** | 待读 |

#### 核心框架：上瘾模型（Hook Model）

全书围绕一个核心模型展开，描述如何通过四步循环让用户养成使用习惯：

```
触发 → 行动 → 多变的酬赏 → 投入 → （再次触发）
```

| 阶段 | 关键问题 | 要点 |
|------|---------|------|
| **1. 触发（Trigger）** | 是什么激活了用户行为？ | 分外部触发（推送、广告、口碑）和内部触发（情绪、习惯、需求）。终极目标是让外部触发内化为内部触发——用户一有某种情绪就想到你的产品 |
| **2. 行动（Action）** | 用户做了什么最简单的行为？ | 行动 = 动机 × 能力 × 触发（Fogg 行为模型）。降低门槛比提高动机更有效——先让用户"动起来" |
| **3. 多变的酬赏（Variable Reward）** | 用户得到了什么不可预测的回报？ | 酬赏分三类：社交酬赏（被认同）、猎物酬赏（获得资源/信息）、自我酬赏（成就感）。关键是"多变"——可预测的奖励很快失去吸引力 |
| **4. 投入（Investment）** | 用户付出了什么增加了留存？ | 用户每次使用时投入的时间、数据、社交关系等，会成为下次触发的铺垫。投入越多，离开成本越高（沉没成本 + 存储价值） |

#### 对产品/运营工作的启发

1. **用户运营**：不要只盯 DAU，要看用户是否进入了"触发→行动→酬赏→投入"的闭环。如果用户只行动无酬赏，留存必然断裂
2. **增长策略**：降低首次行动门槛（能力），比砸钱提高动机更高效。先让用户"用起来"，再逐步引导投入
3. **内容/社区运营**：多变酬赏是粘性核心——信息流、评论区、点赞机制的设计本质上都在制造不可预测的社交酬赏和猎物酬赏
4. **用户分层**：已进入投入阶段的高价值用户是留存基本盘，触发阶段的新用户需要最小化行动路径

#### 一句话总结

> 习惯不是被设计的，是被"钩住"的——找到用户的内部触发，用最低门槛的行动和多变的酬赏循环，让每一次投入都成为下一次触发的起点。
